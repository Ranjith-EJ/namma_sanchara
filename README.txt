NAMMA SANCHARA ADVENTURES — DEMO WEBSITE
==========================================

Files
-----
- index.html  : Website structure and content
- style.css   : Responsive styling
- script.js   : Navigation, trip filters, favourites and WhatsApp enquiry actions

How to run
----------
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html, or open it in Chrome/Edge.
4. Internet connection is needed for Google Fonts and the sample Unsplash photos.

Customise before publishing
---------------------------
- Replace sample trip names, destinations, dates, prices, itineraries and inclusions with verified details.
- Replace sample gallery photos and sample review quotes with the company's own approved content.
- Confirm phone numbers, WhatsApp links and community invite link.
- Add the correct cancellation/refund, safety, privacy and booking terms.
- The page is an unofficial demo concept, not an official live website.
